# KBC Game - Python Implementation

A simple, interactive command-line interface (CLI) version of the famous game show **Kaun Banega Crorepati**, built using Python.

## 🚀 Features
* **Progressive Difficulty:** Questions get harder as the prize money increases.
* **Score Tracking:** Keeps track of your 'Balance' as you progress through the levels.
* **Input Validation:** Handles both option numbers (1-4) and text-based answers.
* **Win/Loss Logic:** Includes specific prize "milestones" for incorrect answers.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Concepts Used:** Functions, Loops (`while`), Conditional Logic (`if-else`), and Lists.
